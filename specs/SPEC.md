## 1. Problem / Goal
What is this software for? (e.g., "Keep track of all my professional certificates — courses, licenses, diplomas — in one place, with the files attached and easy to search.")

## 2. Users
Who uses this? Just you, or others too (family, team, clients)?

## 3. Core features
List the things you need to do with a certificate. Examples to prune/extend:
- Add a certificate (upload file: PDF/image)
- Edit/delete a certificate
- View certificate details
- Search / filter (by name, issuer, date, tags, category)
- Expiration tracking & reminders (e.g., notify 30 days before expiry)
- Categories/tags (e.g., "Security", "Cloud", "Language")
- Export list (CSV/PDF)
- Attach multiple files per certificate (certificate + transcript, etc.)

## 4. Data to store per certificate
- Title / name
- Issuing organization
- Issue date
- Expiration date (if any)
- Credential ID / verification URL
- File(s) attached
- Tags / category
- Notes
